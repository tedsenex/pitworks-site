01 SHOW CAR

藍色幽靈 // YAMAHA R1

SHOW CAR STREET FIGHTER 台北製造
DETAILS

由台北 Pit Works Design 的 Ted Lee 打造，以 1998 Yamaha YZF-R1 為基礎，靈感來自經典小精靈遊戲中的藍色幽靈「Inky」。全車以 3D 列印、CNC 加工與碳纖維複合材料為核心，徹底重塑車體美學。

EXTERIOR // 外觀

  • 油箱裁切縮短比例，外覆訂製鋼製油箱
  • 鑄鋁加油口蓋（仿耐久賽復古造型）
  • 透明導流罩：感光環氧樹脂 3D 列印，拋光透明上漆
  • 全新方形鋼製副車架（CAD 建模 + 傳統金屬成型）
  • 主色青藍配色，致敬 Pac-Man 幽靈 Inky

性能 // CUSTOM PARTS

  • 碳纖維上三角台 + Koso 儀錶整合座艙
  • 客製分離把手：碳纖維桿 + CNC 鋁製夾具 + Koso 握把
  • 碳纖維水箱護網 + 後輪整流側蓋
  • 客製排氣管（鋁合金 + 碳纖維），3D 列印品牌徽章
  • Frando 來令片 / HRC 煞車油管 / Over 腳踏控

03 SHOW CAR

電動 DAX // HONDA DAX 電動改裝

SHOW CAR ELECTRIC 委託案
DETAILS

由 客戶委託 × Pit Works Design 完成。以 Honda DAX 迷你小車為原型，將其全面升級為電動驅動。馬達支架以原廠引擎外型為參考原創設計，3D 列印原型後轉鑄鋁量產，讓改裝視覺上完全融入原車比例。

EXTERIOR // 外觀

  • 原型車：Honda DAX 迷你型小車
  • 客製化迷彩鯊魚轟炸機主題塗裝
  • LED 大燈升級
  • 馬達支架外型參考原廠引擎設計，視覺融合度高

性能 // CUSTOM PARTS

  • 馬達支架：3D 列印原型 → 鑄鋁量產製造
  • 電動馬達驅動系統
  • 鋰電池組整合
  • 全車電動化改裝
